Q-CODE NOTAM

🌐 SOFIA 🗺 AZBA
●

Collez tout le briefing SOFIA et réglez votre vol : l'appli met de côté ce qui ne vous concerne pas.

🟪 Mes zones

Carte aéronautique open flightmaps (cycle AIRAC en cours) — nécessite une connexion ; les zones déjà affichées restent consultables hors connexion. Touchez un numéro pour le détail.

Aide au décodage — ne remplace pas la lecture du NOTAM complet.

Mode d'emploi

Aide à la préparation — ne remplace ni SOFIA, ni l'AZBA, ni la VAC.

0. Une seule fois : créer le raccourci « Copier SOFIA »

Il copie toute la page SOFIA d'un coup (sans sélectionner à la main).

  1. Réglages → Apps → Raccourcis → Avancé : activez Autoriser l'exécution des scripts.
  2. App Raccourcis → ＋ → renommez-le Copier SOFIA.
  3. Ajoutez l'action Exécuter JavaScript sur une page web, effacez le texte proposé et mettez seulement :
    completion(document.body.innerText);
  4. Ajoutez l'action Copier dans le presse-papiers.
  5. Bouton ⓘ en bas → activez Dans la feuille de partage → ✓.
  6. En haut, ligne « Recevoir … depuis Feuille partagée » : touchez le premier mot bleu → Effacer → cochez seulement Pages web Safari → ✓.
  7. Dans « Exécuter JavaScript sur Page web », touchez Page web → Entrée du raccourci.
  8. ‹ pour sortir (enregistrement automatique).

Sans raccourci : sur la page SOFIA, appui long sur le texte → faites glisser jusqu'en bas → Copier.

1. Avant chaque vol : la routine
  1. Dans l'appli, touchez 🌐 SOFIA (en haut) et faites votre briefing (PIB trajet).
  2. Sur la page du briefing : Partager (carré avec flèche) → faites défiler tout en bas → Copier SOFIA (la 1ʳᵉ fois : Autoriser).
  3. Appli → Trier → 📋 Coller : heure, durée, plafond et route sont repris.
  4. Ajustez la durée réelle du vol (SOFIA met souvent 12 h).
  5. Lisez « À lire » : le plus important est en haut (zones R, avertissements W, GNSS, obstacles).
  6. Carte : vérifiez la route au milieu des repères.
  7. 🗺 AZBA : ouvrez la liste ☰ (en haut à droite), puis Partager → Copier SOFIA, et dans l'appli Trier → 📋 Coller : les zones RTBA actives pendant votre vol s'affichent (le briefing NOTAM est conservé).
2. Onglet Trier
  • À lire : NOTAM actifs pendant votre vol et sous votre altitude, cochés par défaut.
  • Écartés : hors créneau, au-dessus de vous, IFR seul, administratif, ou déclencheur TT « activable par NOTAM ». Jetez-y un œil.
  • ⚠ Déclencheur de SUP AIP sans activation par NOTAM : la zone peut être active selon le SUP lui-même (ex. ZRT Ochey) → lisez le SUP.
  • ⚠ Briefing produit il y a… : briefing ancien, refaites-le.
  • Touchez un NOTAM pour l'ouvrir ; les cases cochées vont dans 📖 Lire et 📄 PDF.
3. Onglet Carte — OFM
  • Bandeau en haut : votre créneau (heure de Paris). Touchez-le pour le modifier.
  • Route : codes OACI (LFGY LFSN) ou points ; ✎ pour ajouter / déplacer / supprimer un point sur la carte.
  • Vol local : « LFGY » seul → cercle de rayon réglable.
  • Numéros = NOTAM cochés (touchez pour le détail). Λ = obstacle. Pointillés = cercle indicatif (bouton ◯ pour les masquer).
  • ⛶ plein écran, ✕ Quitter en bas pour sortir.
4. Mes zones (ZRT d'un SUP AIP)
  1. Dans le SUP AIP (PDF), rubrique Limites latérales / Lateral limits : copiez tout le bloc de coordonnées (arcs et cercles compris).
  2. 🟪 Mes zones → ＋ Ajouter : tapez le nom, plancher, plafond, remarque (horaires, fréquence).
  3. Collez dans la grande case → « ✓ X coordonnées lues ».
  4. 👁 Aperçu, comparez avec le dessin du SUP (ou SkyDemon), puis ✓ Enregistrer.

🎯 centrer · 👁/🚫 afficher/masquer · ✎ modifier · 🗑 supprimer (pensez-y à la fin du SUP). Touchez l'intérieur d'une zone (hors numéros) pour sa fiche.

5. Ma capture (Bossy / AZBA)
  1. Capture d'écran de la carte (nord en haut). Pour l'AZBA : réglez d'abord 📅 sur l'heure du vol.
  2. 🖼 Ma capture → Carte Bossy ou Carte AZBA → 🖼 Capture.
  3. Calage en 2 points, éloignés et en diagonale :
    • Bossy : croisement du quadrillage (degrés écrits au bord) ou centre d'un terrain + code OACI ;
    • AZBA : petit rond d'une ville + son nom (Nancy, Mulhouse…).
  4. Route, NOTAM et zones s'affichent dessus ; 📤 Partager pour l'image.

Repères décalés ? Un degré mal saisi : ↺ Recaler.

6. Décoder, Lexique, Chercher, Codes
  • Décoder : un code Q (QRRCA) ou un NOTAM entier → explication et « en vigueur maintenant ? ».
  • Lexique : abréviations (PPR, HJ, RDL…).
  • Chercher : un mot (voltige, piste…) → le code Q correspondant.
  • Codes : liste complète des sujets et états.
7. Bon à savoir
  • NOTAM et AZBA sont en UTC ; l'appli affiche l'heure de Paris (UTC +2 l'été, +1 l'hiver).
  • Le RTBA n'est jamais dans les NOTAM : seulement sur l'AZBA.
  • TT = déclencheur de SUP AIP, pas une activation.
  • Vos données (briefing, zones, captures) restent sur ce téléphone.
  • L'appli se met à jour toute seule : le numéro de version est affiché en bas.
